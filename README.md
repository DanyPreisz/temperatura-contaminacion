# Predicción de Temperatura o Contaminación

Proyecto de regresión / series de tiempo listo para Google Colab. Incluye EDA, lags, modelos y SHAP.

## Abrir en Google Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/DanyPreisz/temperatura-contaminacion/blob/main/temperatura_contaminacion_colab.ipynb)

## Contenido

- Serie de temperatura diaria simulada (ciclo anual + ruido)
- Features: lags, media móvil, humedad, viento
- EDA (plot de serie, scatters)
- Modelos: Ridge, Random Forest, Gradient Boosting
- Feature importance
- **SHAP** (summary plot)
- Conclusiones

Datos: simulados

Rango esperado (ejemplo): R² > 0.80
